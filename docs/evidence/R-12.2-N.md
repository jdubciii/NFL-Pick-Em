### 2.2 Root Cause Analysis of Cross-Schema Contamination
1. **Direct Query Discrepancy:** Test fixture setup in `tests/wrapUpConcurrency.test.ts` used explicit raw SQL targeting `rehearsal.weekly_wrapups`.
2. **Application Query Target:** `runWeeklyWrapUp()` imported the default `prisma` client from `src/db/client.ts`. Prisma model queries compile with unqualified table names (`"public"."penalty_ledger"` / default schema).
3. **Environment Misconfiguration:** Prior to Decision #32, `.env` pointed directly to Supabase (`aws-0-us-east-1.pooler.supabase.com`), causing the transaction inside `runWeeklyWrapUp` to write to the hosted public database.
4. **Resolution:** Decision #32 permanently flipped `.env` to `localhost:5432/pickem_rehearsal`, isolated hosted credentials to `.env.hosted`, and wired `assertDisposableUrl` into Vitest global setup.
